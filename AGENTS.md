# Agent Guidelines

## Emoji Prohibition Policy

All AI agents operating within this project must strictly comply with the following instructions:

1. **No Emojis**: Do not use emojis (Unicode pictographs or emoji symbols) in code, comments, documentation, UI text, logs, error messages, commit messages, or responses.
2. **Text Descriptors**: When status or category labels are needed, use concise bracketed text indicators (e.g., `[OK]`, `[ERROR]`, `[WARNING]`, `[INFO]`, `[DONE]`, `[In Progress]`).
3. **UI Elements**: Use dedicated vector icons (e.g., Lucide React or standard SVG components) instead of unicode emoji characters for user interface presentation.
